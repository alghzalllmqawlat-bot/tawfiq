دليل سريع — أداة إنشاء موقع WordPress تجريبي تلقائيًا (مناسبة لاستضافة InfinityFree)

ملخص الفكرة
- هذه الحزمة تحتوي على سكربت PHP (auto-installer.php) وملف إعداد (setup.json) باللغة العربية.
- تعمل على تثبيت/تنشيط قالب وإضافات وإنشاء صفحات وتطبيق إعدادات أساسية داخل تثبيت WordPress الموجود على InfinityFree (بدون SSH).

قبل التشغيل — تحذيرات مهمة
1. أنشئ نسخة احتياطية لقاعدة البيانات والملفات قبل التشغيل.
2. استبدل قيمة "secret" في setup.json بمفتاح قوي وفريد.
3. بعد نجاح التنصيب احذف auto-installer.php و setup.json فورًا من الخادم.
4. لا تضع مفاتيح تراخيص أو بيانات حساسة داخل setup.json على الخادم العام.

الخطوات العملية
1. ثبت WordPress في حساب InfinityFree (يمكن استخدام Softaculous داخل لوحة التحكم أو التثبيت اليدوي).
2. افتح مدير الملفات (File Manager) أو FTP وادخل إلى مجلد public_html.
3. ارفع هذين الملفين:
   - auto-installer.php
   - setup.json
4. افتح المتصفح وادخل:
   https://YOUR_SITE/auto-installer.php?key=YOUR_SECRET_KEY
   (استبدل YOUR_SITE و YOUR_SECRET_KEY بالقيم المناسبة)
5. راجع سجل التشغيل الذي يظهر في المتصفح. إذا ظهرت رسائل نجاح، احذف الملفات المؤقتة فورًا.
6. فعّل SSL المجاني من لوحة InfinityFree إن لم يتم تفعيله تلقائيًا، ثم غيّر إعدادات الموقع في لوحة WordPress إلى https.

ملاحظات إضافية
- بعض الإضافات قد تحتاج تفعيلًا يدويًا أو إعدادات بعد التثبيت.
- لإضافات مدفوعة: ضع ملف ZIP بدل الـ slug في حقل "plugins" داخل setup.json أو نفّذ التفعيل اليدوي بعد رفع ملف التفعيل.
- لاحقًا، عندما تنتقل لاستضافة بدعم SSH وWP‑CLI، نُحسّن الأداة لتصبح آلية بالكامل بدون رفع ملفات يدوية.
